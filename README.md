# GabAI — Your On-Device AI Guide, Anytime, Anywhere!

<img src="assets/images/gabai-logo.png" alt="GabAI logo" width="100" />

**GabAI** comes from the Filipino word *“gabay,”* meaning *guide*. It is an offline Android AI assistant that helps users understand confusing on-screen content through simple explanations in English or Filipino.

## Key Features

- **Offline AI Assistant** — Powered by Qwen3 0.6B running locally.
- **Floating Assistant** — Get help while using other apps.
- **Screenshot Explanation** — Understand on-screen content using OCR and AI.
- **Contextual Chat** — Ask questions and receive follow-up explanations.
- **Bilingual Support** — English and Filipino.
- **Chat History** — Access previous conversations offline.

## Problem It Solves

GabAI helps bridge the digital literacy gap by making confusing smartphone interfaces, notifications, and instructions easier to understand, anytime and anywhere.

## Why Run AI Locally?

GabAI can process sensitive on-screen information, including private messages, banking notifications, and personal documents. By running Qwen3 0.6B directly on the device, AI processing stays local, helping protect user privacy.

On-device AI also allows GabAI to work without an internet connection, making it accessible in areas with poor connectivity. It eliminates dependence on cloud AI servers and per-request API fees, providing a more reliable and cost-efficient experience.

## Tech Stack

| Area | Technology |
| --- | --- |
| Local AI Model | Qwen3 0.6B |
| On-Device OCR | Google ML Kit OCR |
| Frontend | React Native, Expo, TypeScript, NativeWind |
| Native Android | Kotlin, MediaProjection, Overlay APIs |
| AI Inference | llama.rn |

## Disclosures

- **APIs & Cloud Services:** Android native APIs and on-device Google ML Kit OCR; no cloud AI inference APIs.
- **Existing Assets:** Nunito font and ChatGPT-generated illustrations.
- **AI Development Tools:** OpenAI Codex, ChatGPT, and Figma AI.
