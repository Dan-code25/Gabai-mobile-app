# History and Settings

Implemented in `src/app/history.tsx` and `src/app/settings.tsx`, using the existing bottom navigation, cream/pastel theme, local Nunito fonts, and root Chat provider. No new dependencies.

- History lists newest updated conversations, searches titles/messages locally, restores messages and original OCR context in Chat without rerunning OCR, and confirms individual deletion. Further replies update the same ID. Deleting the active chat resets/cancels it safely.
- Settings contains only English/Filipino language preference and About GabAI, with the configured app version.
- `src/storage/appData.ts` serializes writes through the installed Expo FileSystem library to app-private `files/gabai-data/`: one versioned JSON per conversation and `preferences.json`. Temporary writes are moved into place. Records include IDs, timestamps, roles, screenshot metadata and source text; screenshot images/URIs are excluded. Native captured crops remain temporary and are discarded after processing. Corrupted records are reported and retained, rather than silently deleted.
- `src/i18n/translations.ts` centralizes interface labels. The root store drives both Home and Settings selectors and updates screens immediately. The existing `updateChat` JSON bridge supplies the same labels to Kotlin, including while the assistant is disabled. Live changes update overlay controls/status/crop instructions without losing conversation or typed input.
- The existing singleton AI service reads the chosen language for future requests. Original OCR, saved titles and previous conversation messages remain unchanged. The existing explanation prompt/language checks are reused; follow-up prompts now carry the same language instruction and bounded recent history.
- Android cloud backup is disabled in app config and the native manifest so conversations are not included in automatic Google Drive backup. Android's policy is documented at https://developer.android.com/identity/data/autobackup and Expo configuration at https://docs.expo.dev/versions/v57.0.0/config/app/#allowbackup.

Validation: TypeScript and Expo lint passed. `scripts/check-history-settings.cjs`, `scripts/check-chat-tab.cjs`, and `scripts/check-floating-chat.cjs` passed: persistence across simulated restart, preferences, search/order, updates with stable ID, deletion/write race, malformed-file recovery, restored OCR follow-ups without another OCR call, language propagation, serialized model use, prompt budget/cancellation and thinking-tag filtering. Native Android debug build succeeded in 1m24s and installed on RMX2061 without clearing app data. The phone showed the translated Settings screen and saved History entry, keeping its earlier English answer unchanged after selecting Filipino. Development server remains on port 8083.

User confirmed reopening saved Chat, a new answer with Filipino selected, saved history after restarting, and retained language preference work. The Filipino Settings label is shortened to "Settings" as requested. Screenshot follow-up after reopening History and translated floating controls/crop flow still need physical confirmation. Qwen 0.6B language quality can vary; the application uses prompt instructions and one retry for clearly wrong-language output, without claiming a fluency guarantee.

Existing conversations created before persistence was introduced cannot be recovered from an earlier app process that has already closed.
